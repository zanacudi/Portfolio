Inverse Modelling of Saturated–Unsaturated Volume Change of Tailings

An interactive companion to Taher, Scalia & Bareither (2024), International Journal of Geotechnical Engineering, 18:7–10, 788–801. doi.org/10.1080/19386362.2024.2435447

What this paper actually does

Tailings columns settle over time as excess pore water drains and the material consolidates under its own weight. That process can be forward-modelled if you already know two constitutive relationships from lab tests: how void ratio changes with effective stress, and how hydraulic conductivity changes with void ratio. The problem is that when you only have field sensors (not lab tests), the hydraulic conductivity relationship — specifically two fitting parameters, C and D — is very hard to measure directly, especially at the very high void ratios found in freshly deposited tailings.

This paper's contribution is an inverse model: start from a full physics-based forward model (built on the PDE below, solved in MATLAB with PDEPE), then wrap it in a nonlinear least-squares optimizer (LSQNONLIN, trust-region-reflective algorithm) that searches for the values of C and D that make the model's predicted settlement curve match a real measured curve. Below, you get to be the optimizer: drag the sliders for C and D yourself and watch the predicted curve chase the "measured" data, then compare your answer to the actual back-calculated values reported in the paper's Tables 4 and 5.

Governing equations (click to expand)
Void ratio – effective stress: e = A(|σ − ue| + Z)B   (Eq. 2)
Hydraulic conductivity – void ratio: ksat = C·(e)D   (Eq. 3) — C and D are what you're solving for below
Governing PDE (self-weight consolidation): 1/(1+e0) · ∂e/∂ue · ∂ue/∂t = ∂/∂y (k · (1/γw) · (∂ue/∂y)gce)   (Eq. 1)

The full study solves Eq. 1 directly with a finite-element PDE solver. The interactive tool below uses a calibrated closed-form approximation instead (exact at the endpoints, physically anchored through Eqs. 2–3) so it can run instantly in a browser — see the disclaimer at the bottom.

Educational surrogate. This tool does not re-implement the paper's finite-strain PDEPE/LSQNONLIN solution. The equilibrium (final) height is computed exactly from the actual A, B, Z, e₀, Gₛ and column height using Eq. 2, integrated over the solids coordinate — permeability doesn't affect the final settled height, only how fast it's reached. The settlement rate uses a calibrated closed-form curve whose sensitivity to C and D mirrors Eq. 3, tuned so the paper's actual parameters reproduce the reported column-test duration. Do not use this for design.
