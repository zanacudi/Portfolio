From “dense or loose?” to a computable model of soil response

This module builds the one mental model needed for the rest of the book: compare the current soil state with the critical state at the same mean effective stress. The distance between them, ψ, organizes contraction, dilation, peak strength, and the direction of the stress–strain response.

About this module

This book builds its entire treatment of liquefaction — static and cyclic, laboratory and in-situ, case histories and constitutive models — on one idea: a soil's behavior is governed not just by its density or its stress level alone, but by how far it sits from the critical state, the unique void ratio a soil settles into after enough shearing at a given effective stress. That distance is the state parameter, ψ. Everything downstream — whether a sand contracts or dilates, how strong it is, whether it can flow-fail — is, to first order, a function of ψ and a small number of soil properties.

This first module works through that mathematical core using the book's own real, published data: the critical state properties of 17 sands and tailings from Table 2.11, and the NorSand constitutive model derived in Chapter 3. From here, Module 2 covers in-situ determination of ψ from CPT data (Chapters 4–5), and Module 3 and Module 4 cover the static and cyclic liquefaction triggering framework (Chapters 6, 7 & 9) that this all leads to.

Particle-scale intuition

Dense of critical, ψ < 0
Particles need extra room to rearrange during shear. The assembly tends to dilate and can mobilize a peak stress ratio above M.
Loose of critical, ψ > 0
Particles can collapse into available voids. The assembly tends to contract and may generate positive pore pressure if drainage is prevented.

1. The critical state line & the state parameter ψ

Every real sand has its own critical state line (CSL) — the void ratio it reaches at large shear strain, as a function of confining stress — commonly idealized as semi-log:

ec = Γ − λ·ln(p′)   (Eq. 2.1 exactly as printed — natural log)

The book is explicit that both forms are in everyday use, and gives the exact conversion: natural logs (λ) are more convenient for constitutive modelling, base-10 logs (λ10) arise naturally when plotting lab data by hand — λ10 = 2.303·λ. Table 2.1 and the rest of this page use λ10, so here is the same line written that way — toggle to confirm they trace out the identical curve below:

ec = Γ − λ10·log10(p′)   (identical line, λ10-form — used throughout this page)

Outside this book: the semi-log form above is Jefferies & Been's own idealization, but it isn't the only one in use. Li & Wang (1998)* showed that plotting e against (p′/pa)ξ instead of log(p′) often straightens the CSL further — useful because the semi-log form can bend noticeably at low stress for some sands.

ec = eΓ − λc·(p′/pa)ξ

Three fitted parameters — eΓ (intercept), λc (slope), and the exponent ξ — play the same roles as Γ and λ10 above, with pa a reference (atmospheric) pressure. It's a genuinely different curve shape, not just a rewritten version of Eq. 2.1, so it isn't plotted on the chart below alongside the book's own real Table 2.1 values — there's no published eΓ/λc/ξ fit for these particular sands to show without inventing numbers.

* Li, X.S. & Wang, Y. (1998). "Linear representation of steady-state line for sand." Journal of Geotechnical and Geoenvironmental Engineering, ASCE, 124(12), 1215–1217.

The state parameter is simply the current void ratio's distance from that line at the current stress:

ψ = e − ec   (Eq. 2.6) — ψ < 0: denser than critical (dilative) · ψ > 0: looser than critical (contractive)

2. Stress–dilatancy: how ψ sets strength

Dilatancy, D, is the ratio of the volumetric strain increment to the shear (deviatoric) strain increment, D = dεv/dεq (Eq. 2.4) — how much a soil is bulking up or compacting for a given amount of shearing. Under the book's compression-positive sign convention, D is negative while a sample is dilating, so its most negative value during a test — usually reached at peak strength — is written Dmin. Dilation at peak strength scales linearly with ψ through a soil property χtc (fit from the same triaxial database):

Dmin = χtc·ψ   (Eq. 2.11)

One more property is needed before going further: Mtc, the critical stress ratio η = q/p′ a soil in triaxial compression heads toward at large strain — the same flat target every sample converges to eventually, whatever ψ it started at (that's the whole point of "critical"). It's a property of the sand itself, not of its current density, and you'll see exactly how it's measured in Section 3. Rowe/Nova's stress–dilatancy rule2 (D = M − η) then converts dilation directly into a peak stress ratio above (or below) that critical value Mtc, which converts to a peak friction angle via the standard triaxial Mohr–Coulomb relation sinφ′ = 3η/(6+η):

2. Rowe's 1962 original relates mobilized friction to dilation through a more elaborate ratio derived from a sliding-block energy analysis; the simple linear form D = M − η used throughout this page is Nova's later simplification, which the book adopts for its convenience in constitutive modelling.
ηmax = Mtc − Dmin    sinφ′peak = 3ηmax / (6 + ηmax)

3. Where do Γ, λ10, Mtc, χtc, N and H actually come from?

NorSand's six soil properties aren't looked up in a table — every one of them is fit to a plot of laboratory test results. The panels below use the sand currently selected in Section 1 (Erksak 330/0.7 sand) and show, for each parameter, an illustrative set of test points scattered around that sand's real published value, then fit a line or curve through them right in front of you — the same logic the book uses on real data (Sections 2.4, 2.6, 3.7). The scatter points are synthetic (generated to plausibly resemble real test data), but the target value each one is built around is the real number from Table 2.1 — see the disclosure at the bottom of this page.

Even the book's own numbers aren't perfectly unique. Section 2.5, "Uniqueness of the CSL," is upfront that repeat calibrations of the same sand rarely land on identical properties. Erksak 330/0.7 is the book's own example: Chapter 3's validation (Section 3.7.1) uses Γ=0.816, χtc=3.5; Chapter 6's flow-liquefaction case study recalibrates the same sand to Γ=0.817, χtc=3.8 — both with the same Mtc=1.26 and λ10=0.031. This page uses the Chapter 3 values throughout. The gap is small, but it's a real, book-documented illustration that "critical state properties" are a best-fit from a finite test program, not a physical constant read off nature.3

D. N and H — fit to the whole curve, not read off one plot

Unlike the four properties above, N and H have no single defining plot — the book calibrates them by iterative forward modelling: running NorSand and adjusting N and H until the predicted stress–strain curve matches a real measured one (Ch. 3, Section 9.3.6). Try it yourself: drag N and H below until the navy model curve tracks the grey "measured" points as closely as possible.

If you fit each of the six tests above separately, you generally get six slightly different (N, H) pairs, not one. That's normal, not an error — real stress–strain curves carry test-to-test scatter, so a forward fit to one curve alone will always land on a slightly different compromise than a fit to another. The single (N, H) reported for a sand is a best compromise across the whole program (or a fit to one representative, well-behaved test), chosen to track every curve reasonably well rather than any single one perfectly — the same calibration humility already flagged for Γ and χtc in the box above.

The seventh (and eighth) properties: elasticity, Ir and ν

NorSand needs seven properties in total — the six above plus a Poisson's ratio ν. Elasticity itself is set by a single dimensionless number, the rigidity index Ir = G/p′ (elastic shear modulus over mean stress, Table 3.2's typical range 100–600 for sands): high Ir means the soil is very stiff relative to how hard it's being confined (dense, heavily overconsolidated), low Ir means it's compliant relative to its confinement (loose, lightly stressed). This simulator neglects elastic strains entirely (disclosed below), so Ir plays no role in the curves above — but you can still see what it represents:

Governing equations used (all from Table 3.1 and Eqs. 3.31–3.39)4

4. Table 3.1's full critical-stress-ratio expression also carries a Lode-angle dependence for general (non-triaxial-compression) stress states: M = Mtc − (Mtc2/(3+Mtc))·cos(3θ/2 + π/4). This simulator is restricted to triaxial compression, where that expression reduces exactly to M = Mtc — which is why it doesn't appear below.

These seven equations aren't independent facts to memorize — they're one computational loop, repeated every strain increment. Each line feeds the next; the last line feeds back into the first for the next step:

1 · How far the internal yield surface currently is from critical
ψi = ψ − λ·ln(p′/pi)

Uses the internal variable pi, not p′ directly — this is what lets the yield surface evolve independently of the real stress path.

↓
2 · A fixed property of the sand, rescaled once (not every step)
χi = χtc / (1 − χtcλ/Mtc)

Converts χtc (fit in Section 3) into its "image" form — a constant for this sand, computed once at the start.

↓
3 · The model's evolving target
Mi = Mtc − χiN|ψi|

χi and the current ψi from step 1 combine to set the image stress ratio — how far the yield surface's target currently sits from Mtc.

↓
4 · Where the model actually is right now
η = Mi·(1 − ln(p′/pi))

At the current pi and p′, this is the stress ratio the yield surface predicts this instant.

↓
5 · The gap between "heading toward" and "is" becomes motion
Dp = Mi − η

This is the actual plastic dilation rate for this increment — the same D = M − η rule from Section 2, now evaluated with the image values. It's what moves e.

↓
6 · Where pi itself is drifting toward
pi,max = p′·exp(−χiψi/Mi)

Mi and ψi also set the size the yield surface is trying to grow (or shrink) toward.

↓
7 · How fast it actually gets there — then repeat from step 1
Δpi = H·(pi,max − pi)·Δεq

H sets how quickly pi catches up to pi,max each increment. Advance pi by this amount, then go back to step 1 for the next slice of strain.

About this tool. Section 1's critical state line parameters (Γ, λ10, Mtc, χtc) for all 17 sands/tailings are transcribed directly from Table 2.1 of the book. Section 2's formulas (Eq. 2.11, Rowe/Nova stress–dilatancy, and the standard triaxial sinφ′=3η/(6+η) conversion) are exact. Section 3's "sample triaxial test program" table is illustrative, not a real lab data sheet: the confining stresses and target ψ0 values are chosen to give a representative spread from loose to dense, and every other column (e0, peak η, φ′peak, Dmin) is then computed exactly from this sand's real Table 2.1 properties using the same equations shown throughout this page — it's meant to show the shape and structure of real triaxial data, not to reproduce any specific test. The "one test, start to finish" pipeline directly beneath the table works the same way: the "raw" q and εv curves are a NorSand simulation (this sand's real properties) with pseudo-random noise added at sparse sample points, and the stress–dilatancy plot's (D, η) pairs are numerically differentiated from those noisy curves — not read off the smooth model directly — which is why the fitted Mtc doesn't land exactly on the real value, and lands closer for some tests than others: differentiating noisy data amplifies scatter, and a test whose D range doesn't reach near zero needs a longer, less reliable extrapolation to the D=0 intercept. Both effects are real phenomena in actual stress–dilatancy data reduction, not artifacts of this tool. The four panels' data points are similarly synthetic, not digitized from the book's actual figures (the book's own real test data isn't available to reproduce here): each panel generates illustrative scatter by taking this sand's real, published Table 2.1 value (or, for panel D, an illustrative N/H pair) and adding deterministic pseudo-random noise, then fits a line back through the noisy points using ordinary least squares — so the "recovered" value you see should land close to, but not necessarily exactly on, the real one, exactly as happens with real scattered lab data. The underlying relationships used (Eq. 2.1 for the CSL, Eq. 2.11 for χtc, and NorSand's own equations for the Mtc-convergence and N/H panels) are all real and exact; only the "measured" points around them are constructed for illustration. Section 4's NorSand simulator implements the model's real governing equations (Table 3.1) but makes two disclosed simplifications for a browser-friendly explicit integration: (1) the stress path is idealized as constant mean effective stress p′ (the same idealization the book itself uses in Fig. 2.5, and directly imposed here rather than solved via full elastic–plastic coupling), and (2) elastic strains are neglected so that total shear strain is treated as plastic strain (a simplification the book explicitly endorses for stress–dilatancy data reduction in Section 2.1.3). The hardening law uses the simple difference form (Eq. 3.39) rather than its dimensionless reformulation (Eq. 3.40). N and H are not given for Erksak sand in the book's worked example, so the default N=0.30 and H≈4/λ (the book's own stated first-estimate rule, Table 3.2) are used as literature-typical values. All eight sliders (Γ, λ10, Mtc, χtc, N, H, e0, p′0) are freely adjustable and independent of Section 1's sand selector, so you can explore illustrative, made-up combinations — not just the book's own published sands — to build intuition for what each one individually does to the curve; the "Erksak preset" option is just a sensible starting point, not a constraint.
