PM4Sand — Interactive Companion

Interactive companion to Boulanger, R.W. & Ziotopoulou, K. (2017, revised 2018), PM4Sand (Version 3.1): A Sand Plasticity Model for Earthquake Engineering Applications, Report No. UCD/CGM-17-01, Center for Geotechnical Modeling, UC Davis. PM4Sand is the standard bounding-surface plasticity model used with FLAC/PLAXIS for liquefaction-deformation analysis — it uses the same state-parameter idea as the Jefferies & Been modules, and the same penetration-resistance correlations as the CPT Guide module, to turn field data into a full stress-strain constitutive response.

About this module

PM4Sand follows the stress-ratio-controlled, critical-state-compatible bounding-surface framework of Dafalias & Manzari (2004), simplified to plane strain and recalibrated at the equation level so its default parameters reproduce standard design correlations (SPT/CPT-based relative density, shear-wave-velocity-based stiffness, and liquefaction-triggering-based cyclic strength) without extensive laboratory testing. Where Jefferies & Been describe state using the state parameter ψ (difference in void ratio from the critical state line), PM4Sand uses an equivalent but distinct quantity — the relative state parameter index, ξR — built directly from relative density rather than void ratio, because sands rarely have a reliably measured emax/emin in the field. This module walks through how ξR is defined, how it sets the bounding and dilatancy surfaces that control strength and stiffness, and how the model's headline three primary parameters (DR, Go, hpo) are actually calibrated from penetration resistance in practice.

1. Relative state, ξR — the sand-specific stand-in for ψ

PM4Sand positions an empirical critical state line using Bolton's (1986) dilatancy relationship, expressed directly in terms of the relative density the sand would have at critical state for the current confining stress:

DR,cs = R / [ Q − ln(100·p′/pA) ]
ξR = DR,cs − DR

Q≈10, R≈1.0 were Bolton's values for quartzitic sands; PM4Sand's own default is Q=10, R=1.5 (a slight increase used to better match direct simple shear data). As with ψ, ξR < 0 means dense of critical (dilative tendency), ξR > 0 means loose of critical (contractive tendency), and ξR = 0 means the sand is exactly at critical state for that stress level.

2. Bounding & dilatancy surfaces — from ξR to strength

The bounding surface (peak strength) and dilatancy surface (phase transformation) both collapse onto the critical stress ratio M as ξR→0, and diverge from it exponentially as the sand moves further from critical state:

M = 2·sinφ′cv    Mb = M·exp(−nb·ξR)    Md = M·exp(nd·ξR)

Uses ξR from Section 1 above. Defaults: nb=0.50, nd=0.10 (dense of critical); the report notes that for loose-of-critical states these are effectively reduced/increased to nb/4 and 4nd respectively — toggle below to see the effect.

3. Calibrating DR, Go and hpo from penetration resistance

In practice, laboratory triaxial/DSS data are almost never available, so the model's three primary parameters are estimated directly from SPT/CPT and Vs data:

DR = √[(N1)60 / Cd]   (Cd=46)     DR = 0.465·[qc1N/Cdq]0.264 − 1.063   (Cdq=0.9)
Vs1 = 85·[(N1)60 + 2.5]0.25     Go = 167·√[(N1)60 + 2.5]   (m/s, combining the above with default emax/emin)

hpo — calibrated last, and only by iteration

Unlike DR and Go, hpo has no closed-form correlation: it is adjusted by trial simulation until the model's undrained cyclic response matches a target cyclic resistance ratio (CRR), commonly taken from the Idriss & Boulanger (2008) liquefaction-triggering correlation. The report's own three worked examples anchor this relationship:

Note hpo is not monotonic in DR here — it depends on whatever combination of DR and Go was chosen first, which is exactly why the report insists it be calibrated last.

About this tool. All equations above (the ξR/critical-state-line definition, the Mb/Md exponential forms, the DR/Vs1/Go penetration-resistance correlations, and the six secondary-parameter default formulas) are transcribed directly from the report's own Sections 2.2–2.3 and 4.1 (Tables 4.1–4.2), and the Go formula was independently re-derived and numerically checked against the report's own stated example values (476, 677, 890 for (N1)60=6, 14, 26) to resolve an ambiguous OCR extraction — all three matched to within rounding. This module covers the model's calibration inputs and its critical-state/surface framework (Sections 2.2–2.4, 4.1); it does not implement the full incremental plastic stress-strain integration (the fabric-formation history terms, elastic-plastic coupling, and numerical time-stepping of Sections 2.6–2.9 and 3), which requires the actual FLAC implementation to reproduce faithfully. Treat this as a notation and calibration-logic guide, not a substitute for running the model.
