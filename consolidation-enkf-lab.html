Experiment controls

Model and assimilation equations

Reduced-order consolidation model
U(t) = 1 − exp[−α tm]
s(t) = C · H₀ · ln(1 + Δσ/σ′₀) · U(t)
u(z,t) = Δu₀ φ(z) exp[−α tm]

C controls ultimate compressibility, α controls dissipation rate and represents the combined influence of drainage length, permeability, and compressibility, and m controls nonlinearity in time.

Large-strain constitutive concepts
e = e(σ′),   k = k(e)
σ = σ′ + u
∂e/∂t ↔ ∂/∂z [ k(e)/γw · ∂u/∂z ]

Large-strain slurry consolidation requires evolving geometry and nonlinear effective-stress–void-ratio and permeability–void-ratio relationships. This learning tool uses a reduced-order surrogate so the EnKF can run instantly in a browser.

Ensemble Kalman Filter
x = [s, u₁, u₂, u₃, C, α]
xkf,(j) = M(xk−1a,(j)) + ηk(j)
K = Pxy(Pyy + R)−1
xka,(j) = xkf,(j) + K[yk − Hxkf,(j)]

Because ensemble covariance connects the observations to uncertain parameters, surface settlement and pore pressure can jointly update C and α.

Synthetic educational model. This is not a reproduction of the McVay, Townsend, and Bloomquist dataset and is not a validated large-strain consolidation code. Do not use the generated values for design, storage-capacity estimates, or dam-safety decisions.

Research basis: McVay, Townsend, and Bloomquist examined one-dimensional quiescent consolidation of phosphatic waste-clay ponds and compared theory with centrifuge predictions using laboratory-derived material parameters. Related work by Martinez, McVay, Bloomquist, and Townsend described large-strain theory, centrifuge modelling, and an automated large-deformation consolidometer requiring effective-stress–void-ratio and permeability–void-ratio relationships. Sources: Quiescent Consolidation of Phosphatic Waste Clays; Consolidation of Slurried Soils.
